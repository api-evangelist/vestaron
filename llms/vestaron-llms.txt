# Vestaron

> Vestaron is an agricultural biotechnology company founded in 2005 that develops peptide-based
> bioinsecticides derived from the venom of spiders and other venomous species. Its products —
> SPEAR® LEP, SPEAR® RC, SPEAR® T, BASIN™ FLEX, LEPROTEC® and LEPROTEC® WG — deliver novel
> insecticidal modes of action (IRAC Group 32) that are effective on crop pests while being
> gentle on pollinators and beneficial insects. Vestaron publishes no developer program and no
> product API. The only machine-readable surfaces on vestaron.com are the WordPress REST content
> API (wp/v2, anonymously readable) and an OAuth-gated Model Context Protocol endpoint. This file
> was GENERATED by API Evangelist from the live surface — it is not published by Vestaron.

## APIs

- [Vestaron Content API (WordPress REST wp/v2)](https://vestaron.com/wp-json/wp/v2): 37 paths,
  89 operations. Anonymous read on posts (94 newsroom items), pages (34), media (829),
  categories (4), tags (9), comments (0), search (128 objects) and the discovery collections.
  /wp/v2/users and /wp/v2/settings return 401 to anonymous callers; all writes require
  authentication.
- [Vestaron MCP Server](https://vestaron.com/wp-json/mcp/mcp-oauth-server): a WordPress MCP
  Adapter endpoint fronting the site's content estate. tools/list returns 401 mcp_unauthorized;
  authorization is OAuth 2.1 authorization-code with PKCE (S256), single scope `mcp`.
